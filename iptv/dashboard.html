Serverul personal pentru SmartOne pe Samsung. Render găzduiește lista M3U, nu retransmite video.

1. Conectează SmartOne IPTV

În SmartOne pe TV notează TV MAC; pe pagina SmartOne apasă M3u Playlist, introdu TV MAC și linkul de mai jos. Salvează și dă Reload pe televizor.

Adaugă la SmartOne

În SmartOne apar doar fluxurile M3U8 din lista configurată pe server. Nu publica linkul: conține tokenul privat de acces.

Conectează SET IPTV pe Samsung

Pe iPhone, deschide configurarea SET IPTV, introdu codul MAC de pe televizor, alege M3U link și lipește linkul de mai jos la Playlist URL. Este un link compatibil cu verificarea /get.php a aplicației, dar folosește exact aceleași canale ca SmartOne.

Verifică dacă lista de pe server se descarcă și începe corect cu #EXTM3U.

Deschide configurarea SET IPTV

Linkul conține cheia privată a listei; nu îl distribui public. Încearcă întâi perioada gratuită de test a aplicației.

Alternativă: Xtream Codes (dacă M3U nu se importă)

În pagina SET IPTV alege Xtream Codes, nu M3U Link. Copiază separat cele trei valori. Folosește site-ul oficial SETSYSTEME. Fără server suplimentar și fără retransmisie video.

Această metodă folosește API-ul Xtream pentru lista de canale LIVE; nu oferă EPG sau VOD. Dacă o sursă este restricționată, SET IPTV nu va putea reda acel canal.
